# Imágenes del proyecto

Coloca aquí tus propias fotos y súbelas con estos nombres exactos para que se enganchen automáticamente en el README principal (ya está preparado para referenciarlas):

| Archivo | Qué debe mostrar |
|---|---|
| `xiao-esp32c5-sola.jpg` | La XIAO ESP32-C5 sola, sin montar, con la antena visible |
| `round-display-sola.jpg` | La Round Display sola, vista frontal |
| `montaje-desmontado.jpg` | Los dos componentes separados, uno junto al otro |
| `montaje-completo.jpg` | La pantalla ya encajada sobre la XIAO, el conjunto final |
| `dashboard-movil.jpg` | Captura del dashboard web funcionando en un móvil real |
| `pantalla-funcionando.jpg` | La Round Display encendida mostrando la interfaz (Home/Networks/etc.) |

Tamaño recomendado: 1200px de ancho aprox., formato `.jpg` o `.png`. No hace falta que sean profesionales — capturas reales del montaje real son más útiles aquí que fotos de producto.
