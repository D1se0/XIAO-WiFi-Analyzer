# XIAO WiFi Analyzer — Versión básica

Ábrelo con Arduino IDE haciendo doble clic en `XIAO_WiFi_Analyzer.ino` (asegúrate de que esta carpeta se llama exactamente `XIAO_WiFi_Analyzer_Basico`... o renómbrala a `XIAO_WiFi_Analyzer` si Arduino se queja del nombre — el `.ino` y la carpeta contenedora deben llamarse igual).

**Guía completa:** [`../../docs/03-guia-version-basica.md`](../../docs/03-guia-version-basica.md)

Configuración rápida: edita `config.h` para cambiar el SSID/contraseña del Access Point antes de compilar.
