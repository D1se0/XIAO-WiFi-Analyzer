# XIAO WiFi Analyzer — Versión con pantalla

Requiere instalar 3 librerías de terceros antes de compilar (Seeed_GFX, SeeedStudio_lvgl v8.3, Seeed_Arduino_RoundDisplay) — **no lo compiles sin seguir antes la guía completa**, porque el orden de instalación importa.

Ábrelo con Arduino IDE haciendo doble clic en `XIAO_WiFi_Analyzer.ino` (la carpeta contenedora debe llamarse igual que el `.ino` — renómbrala a `XIAO_WiFi_Analyzer` si hace falta).

**Guía completa, con todos los enlaces de descarga:** [`../../docs/04-guia-version-pantalla.md`](../../docs/04-guia-version-pantalla.md)

**Si algo no compila:** [`../../docs/05-solucion-problemas.md`](../../docs/05-solucion-problemas.md) — casi seguro que ya está documentado ahí.
